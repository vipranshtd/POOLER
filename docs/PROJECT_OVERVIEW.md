# POOLER

## Project Description

POOLER is a smart ride-pooling platform designed for colleges, hostels, corporate hubs, and communities.

The platform allows users to create ride pools, discover nearby pools, join temporary ride-sharing groups, communicate through real-time chat, and build trust through reliability scores and ride history.

---

## Problem Statement

People traveling to similar destinations often struggle to find trustworthy companions for ride sharing.

Current solutions focus mainly on booking rides rather than helping users coordinate temporary ride-pooling groups.

---

## Objectives

* Reduce travel costs through ride pooling
* Help users find nearby travelers
* Create temporary ride-sharing lobbies
* Enable communication before travel
* Improve trust through ratings and reliability scores
